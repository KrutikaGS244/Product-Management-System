# Product Management System

A full-stack Product Management System developed using the MERN stack. 
The application allows users to add, view, edit, update, and delete product details.

##  Features

- Add new products
- View all products
- Edit product name and description
- Update existing products
- Delete products
- Product details displayed in a table
- React-based user interface
- REST API using Node.js and Express.js
- MongoDB database integration
- Responsive and simple interface

##  Technologies Used

### Frontend
- React.js
- HTML
- CSS
- JavaScript
- Axios
- React Router

### Backend
- Node.js
- Express.js
- REST API
- CORS

### Database
- MongoDB
- Mongoose
